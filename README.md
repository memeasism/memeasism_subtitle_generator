    <h1>Usage</h1>
    <ol>
        <li>Download or compile</li>
        <li>Run the app</li>
        <li>Enter your text, timecode, fps, and maybe your delay</li>
        <li>Press the copy button to copy the generated text</li>
        <li>Paste into Kdenlive and enjoy!</li>
    </ol>

    <h1>How to compile</h1>
    <ol>
        <li>
            <p>Clone or download the source code zip and extract</p>
            <code>git clone https://github.com/memeasism/memeasism_subtitle_generator.git</code>
        </li>
        <li>Open the directory that the source code is in</li>
        <li>
            <p>Assuming you have rust set up you should be good, otherwise <a href="https://rust-lang.org/" target="_blank" rel="noopener noreferrer">CLICK ME!</a>, then run</p>
            <code>cargo build --release</code>
        </li>
        <li>Open the ./target/release/ folder, and you should see your compiled executable!</li>
        <li>Now that you have the compiled executable, USE IT!</li>
    </ol>
